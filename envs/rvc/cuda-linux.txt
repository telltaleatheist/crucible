# Installed by `crucible install rvc` into ~/.crucible/envs/rvc/ as a venv built
# from the server's own interpreter.
#
# THE ONE DIRECT REFERENCE IN THE REPO, AND WHY IT IS NOT AN INDULGENCE
# ---------------------------------------------------------------------
# `generate convert-dir` — the warm-model batch command this whole job type is
# built on, the one that loads the model once and converts a directory — exists
# ONLY in Owen's fork. The `ultimate-rvc` on PyPI has `generate convert`, one
# file per process, which for a 1,400-sentence book is 1,400 model loads.
#
# Both call themselves version 0.5.11, which is exactly why this is pinned to a
# COMMIT and not a branch: `pip list` would report `0.5.11` for either, so the
# version is not an identity here. `crucible doctor` checks this line against
# `pip freeze`, which writes a git install back out in this same form
# (crucible/workerenv.py, `recipe_direct_refs`).
#
# The commit is the one installed in Owen's working `bookforge-urvc` env, read
# from its `direct_url.json` on 2026-09-13.
#
# A RESOLVED SET, read from a real install
# ----------------------------------------
# What follows is `pip freeze` from `crucible install rvc` on
# Owen's PC (WSL2, Ubuntu, python 3.11.16) on 2026-09-13: every package pip
# resolved, at the version it resolved. The earlier notice that this file was a
# CHOSEN set and not a measured one is discharged by that install; `crucible
# doctor` checks the env against exactly these lines.
#
# One deliberate departure from that env while doing so: it holds
# `torchaudio==2.7.1+cpu` beside a CUDA torch, which is where a hand-built env
# drifted to rather than a decision anybody made. This asks for the matching
# CUDA build at the same version as torch, because a CPU torchaudio silently
# moves resampling off the card.
#
# THE BASE ASSETS ARE NOT HERE
# ----------------------------
# ultimate-rvc also needs a contentvec embedder and an rmvpe pitch predictor
# before it can convert anything. They are the engine's, not any model's, they
# are about 540 MB, and they are NOT installed by this recipe: BookForge ships
# them on a GitHub release (which DESIGN.md section 5 refuses as a weights
# source) and urvc's own first-run downloader is precisely what `URVC_SKIP_INIT`
# turns off. `crucible/jobs/rvc/__init__.py` refuses a job by name
# (`rvc_base_models_missing`) when they are not under `~/.crucible/rvc-base/`,
# and says which files it wanted.
